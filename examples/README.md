# Untappd Scraper API – code examples

Examples for every Untappd endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/beer.sh`](curl/beer.sh) | `bash beer.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| PHP | [`php/beer.php`](php/beer.php) | `php beer.php` |
| PHP | [`php/search.php`](php/search.php) | `php search.php` |
| C# | [`csharp/Beer.cs`](csharp/Beer.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Search.cs`](csharp/Search.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/beer.go`](go/beer.go) | `go run beer.go` |
| Go | [`go/search.go`](go/search.go) | `go run search.go` |
| Java | [`java/BeerExample.java`](java/BeerExample.java) | `java BeerExample.java` |
| Java | [`java/SearchExample.java`](java/SearchExample.java) | `java SearchExample.java` |
| Ruby | [`ruby/beer.rb`](ruby/beer.rb) | `ruby beer.rb` |
| Ruby | [`ruby/search.rb`](ruby/search.rb) | `ruby search.rb` |
| Node.js | [`nodejs/beer.mjs`](nodejs/beer.mjs) | `node beer.mjs` |
| Node.js | [`nodejs/search.mjs`](nodejs/search.mjs) | `node search.mjs` |
